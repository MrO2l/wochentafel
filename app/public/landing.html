Deine Daten: Ende-zu-Ende-verschlüsselt

Termine, Essenspläne, Einkaufslisten sowie dein Name und der Haushaltsname werden bereits auf deinem Gerät verschlüsselt, bevor sie zum Server geschickt werden — mit einem aus deinem Passwort abgeleiteten Schlüssel (Argon2id) und AEAD-Verschlüsselung (XChaCha20-Poly1305).

Was ist verschlüsselt / was nicht
BereichStatus
Wochenübersicht (Termine, Essensplan, Einkaufsliste, Wochenziele) Ende-zu-Ende-verschlüsselt
Wochen-Vorlage Ende-zu-Ende-verschlüsselt
Name, Haushaltsname Ende-zu-Ende-verschlüsselt
Rezepte (Titel, Zutaten, Zubereitung, Bild) Klartext auf dem Server
E-Mail-Adresse Blindindex + verschlüsselt zur Anzeige †
Passwort Nicht Teil der Ende-zu-Ende-Verschlüsselung, aber auch nicht im Klartext gespeichert — als Hash abgelegt

Rezepte sind für die Rezeptsuche und -anzeige weiterhin auf dem Server im Klartext nötig und daher bewusst von der Verschlüsselung ausgenommen. Ist die Verschlüsselung für einen Haushalt aktiv, speichert der Server für die Bereiche oben, die als „Ende-zu-Ende-verschlüsselt" markiert sind — also auch Name und Haushaltsname — nur noch unlesbare Ciphertext-Bytes; selbst bei einem kompromittierten Server lässt sich daraus ohne das Passwort nichts rekonstruieren.

† Bei der E-Mail-Adresse gilt das nur eingeschränkt: Für die Anmeldung wird sie über einen Blindindex nachschlagbar gemacht — einen serverseitig aus der Adresse berechneten kryptografischen Prüfwert (HMAC), aus dem sich die E-Mail-Adresse selbst nicht zurückgewinnen lässt. Die tatsächliche Adresse liegt zusätzlich verschlüsselt vor und wird erst nach dem Entsperren zur Anzeige entschlüsselt. Dafür sieht der Server deine E-Mail-Adresse bei Anmeldung, Registrierung, beim Anfordern eines Wiederherstellungscodes und beim Passwort-Reset jedoch kurzzeitig im Klartext, um diesen Prüfwert zu berechnen — strukturell dasselbe Zugeständnis wie beim Passwort, das der Server für den Hash-Vergleich ebenfalls kurz im Klartext sieht. Das schützt zuverlässig gegen Datenbank-Diebstahl, ein Backup-Leck oder SQL-Injection, aber nicht gegen einen Angreifer, der bereits aktiv Code auf dem laufenden Server ausführt.

Weil der Server dein Passwort und den daraus abgeleiteten Schlüssel nie im Klartext kennt, gibt es keinen klassischen „Passwort vergessen"-Link per E-Mail. Stattdessen erhält jeder Haushalt bei der Einrichtung einen einmalig angezeigten, für den ganzen Haushalt gültigen Wiederherstellungscode, mit dem sich der Zugang bei Bedarf wiederherstellen lässt. Diesen Code gibt es nur bei der Einrichtung zu sehen — er sollte an einem sicheren Ort aufbewahrt werden.
